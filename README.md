# 🚀 RepoNeva

> **Discover. Contribute. Grow.**

RepoNeva is an **AI-powered Open Source Project Discovery Platform** that helps students, developers, and open-source enthusiasts discover repositories that match their interests, skills, and experience level. Instead of searching across multiple platforms, RepoNeva provides a centralized hub where users can explore thousands of open-source projects across **40+ categories**, receive AI-powered recommendations, and find beginner-friendly contribution opportunities.

Designed with a modern and intuitive interface, RepoNeva leverages the **GitHub API**, **NVIDIA AI API**, and **Grok API** to simplify the journey of contributing to open source.

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/your-username/reponeva.git
```

### Navigate to the Project

```bash
cd reponeva
```

### Install Dependencies

```bash
npm install
```

### Start the Development Server

```bash
npm run dev
```
